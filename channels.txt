# Mesa channels. THIS FILE IS THE ONLY PLACE A VERSION IS PINNED.
#
# Fields, separated by any run of whitespace:
#
#   channel   ppa                    version
#
# A push builds every channel listed here. There is no default channel and no
# :latest tag: with several channels published side by side, both would only be
# ambiguous. Every image tag names either the channel or the exact build.
#
# `kisak` is the one to deploy unless you have measured a reason not to -- it is
# the newest tagged stable Mesa. `mesarc` is the 26.2 line, which Mesa itself
# labels a development release. See README.md.
#
# The version must contain the channel's own name (~kisak / ~mesarc). The build
# checks this, because a version pasted into the wrong row would produce an image
# tagged with one channel while carrying the other's driver.
#
# Re-pinning: when a PPA publishes a newer version the exact-version install stops
# resolving and that channel's build fails loudly. That is deliberate. Fix it here,
# and only here. Channels build independently, so one stale pin does not stop the
# others.
