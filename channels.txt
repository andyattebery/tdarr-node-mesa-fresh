# Mesa channels. THIS FILE IS THE ONLY PLACE A VERSION IS PINNED.
#
# Fields, separated by any run of whitespace. The fourth is optional:
#
#   channel   ppa                    version   [hold]
#
# A push builds every channel listed here. There is no default channel and no
# :latest tag: with several channels published side by side, both would only be
# ambiguous. Every image tag names either the channel or the exact build.
#
# `kisak` follows Mesa's tagged point releases, so its version moves when one is
# released. `mesarc` builds snapshots of Mesa's current staging branch (staging/26.2
# as of 2026-08), so its version moves whenever that branch is republished. Neither
# channel is privileged here; which one you run is decided where you deploy.
# See README.md.
#
# The version must contain the channel's own name (~kisak / ~mesarc). The build
# checks this, because a version pasted into the wrong row would produce an image
# tagged with one channel while carrying the other's driver.
#
# The version fields are maintained by refresh-channels.py, which runs daily and
# writes whatever the PPA currently has installable on noble/amd64 -- so these
# rows follow the PPAs rather than recording a decision someone made. A hand edit
# is fine but temporary: the next refresh overwrites it.
#
# To freeze a channel, add `hold` as a fourth field. The refresh then leaves that
# row alone until it is removed, which is how a deliberate pin -- a rollback, or
# sitting out a bad publication -- survives the bot. `hold` is the only value the
# field may take; anything else fails the build rather than reading as "not held".
